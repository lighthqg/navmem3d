# 第一版：预巡视视觉路线导航契约

## 目标

在单个 Marble 房间中，从一个协议给定的已知视觉路线节点出发，依据语言目标到达对应实体的可观察位置。路线在建图巡视阶段获得；系统不读取仿真全局地图或真值。

## 三类离线资产

- `patrol_sequence.json`：`frame_id`、RGB、时间戳、机器人相对运动。允许有相对尺度，不要求全局坐标。
- `visual_route_graph.json`：关键帧节点与经过真实巡视验证的有向/反向边。
- `entity_route_binding.json`：Marble `entity_id` 与候选路线观察节点的关联证据。

## 运行时接口

输入：`start_node_id`、语言目标、当前 RGB、可选短期 odometry。  
输出：路线节点序列、当前进度、目标确认状态、安全停车/需要人工接管状态。

## 禁止输入

`occupancy.png`、floorplan、A 的完整3DGS、世界坐标、`labels.json`、`structure.json`、目标真值坐标。

## 首版验收

1. B 查询得到的目标至少有一个可验证的路线绑定；
2. 给定起点节点可生成到目标节点的图路径；
3. 执行时仅以参考图像和当前观测输出路线进度；
4. 评测器独立计算到达和碰撞，系统不读取评测真值。
